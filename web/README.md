# SDLC Research RAG: web app

React + TypeScript 7 front end (Vite, assistant-ui, shadcn/ui + Tremor BarList, Sigma.js, TanStack Query, nuqs).
It talks to the Python API only through the HTTP contract [`../contracts/openapi.json`](../contracts/openapi.json);
the typed client in `src/lib/api/generated.ts` is generated by orval. Never edit it by hand. See ADR-0019.

```bash
pnpm install
pnpm dev        # http://127.0.0.1:5173; proxies /api to `uv run sdlcrag serve` (:8000)
pnpm gen:api    # regenerate the client after the contract changes
pnpm check      # client fresh, tsc, oxlint, dependency-cruiser
pnpm build
```
